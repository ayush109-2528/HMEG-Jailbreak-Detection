# English-only HMEG scope

Current research concerns English-language jailbreak and prompt-injection detection. All five experts and hierarchical routing are retained. Short prompts, special-keyword inputs, obfuscation, meaning, structural features and instruction manipulation remain in scope.

Language filters and Hindi statistics were removed from the dataset UI. No dataset records, models, saved metrics, database schemas or training code were altered. The augmented track and mixed-language stress snapshot remain historical records; their aggregates are not relabelled as English-only results.

The sourced model uses out-of-fold training predictions for fusion; the older augmented artifact used separate validation predictions. Descriptions preserve both protocols.

Relevant multilingual literature is background only; it does not establish multilingual HMEG capability.
