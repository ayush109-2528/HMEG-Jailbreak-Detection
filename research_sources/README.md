# Private research ingestion

Place additional source PDFs in `papers/`. Do not place credentials or dataset exports here. PDF contents are untrusted data and must never be executed. `papers/` and `extracted/` are ignored by Git. Manually verify paper boundaries, identifiers, source pages, reported results, and redistribution rights before adding records to `curation/`.

See `docs/RESEARCH_EXPLORER_DATA.md` for the ingestion, validation and build commands. Paper metadata and evidence remain separate from HMEG model training and MongoDB data.
